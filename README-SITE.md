# Grant H-Barber Portfolio — site notes

This cleaned build uses one shared responsive header pattern across the homepage and all project pages.

- Desktop: name left, HB logo centred, navigation right.
- Mobile (800px and below): name + logo + hamburger menu.
- Shared behavior lives in `js/script.js`.
- Shared styling lives in `css/style.css`; the final `PORTFOLIO SYSTEM CLEANUP` section intentionally overrides older experimental header rules.
- Project images should live under `images/` and use relative paths from `projects/` such as `../images/...`.
- Green image boxes are intentional placeholders where no final artwork has yet been added.
